# Планер — личный планер дня в одном Cloudflare Worker

PWA + Telegram Mini App + голосовой Telegram-бот + выгрузка в Notion Calendar.
Всё живёт в одном Worker'е на бесплатном тарифе Cloudflare. Без серверов, подписок и n8n.

- **Планер дня** — план блоками по времени, быстрый ввод («созвон 1.5ч в 16:00 завтра #работа !»), «Спланировать день» с автопланом, «Завершить день», привычки, сферы, цикл 12 недель.
- **Синк везде** — телефон, компьютер и Telegram Mini App видят одни данные; работает офлайн, правки долетают за секунды (last-write-wins, pull по серверной ревизии).
- **Голосовой бот** — наговариваешь задачи в Telegram, Whisper расшифровывает, Llama раскладывает по времени, дню и длительности.
- **Notion Calendar** — задачи с датой уходят в Notion каждые 5 минут (односторонний синк).

## Локальный запуск

Нужны Node.js 20+ и npm.

```bash
npm install
npm run build
npm run dev:local        # билд + wrangler dev на http://127.0.0.1:8787
```

В другом терминале получи ключ для браузера (локальный тестовый пользователь):

```bash
node scripts/devkey.mjs  # напечатает ключ
```

Открой http://127.0.0.1:8787, вставь ключ, войди. В «Настройки → Демо-данные» — кнопка,
наполняющая экраны примерами.

Локально (`wrangler.local.toml`) нет биндинга AI — голосовой бот и Llama-разбор вернут понятную
ошибку, всё остальное (синк, планер, экраны) работает. Отдельно фронт без бэкенда: `npm run dev`
(проксирует /api на :8787).

Тесты:

```bash
npm test                 # 36 тестов: парсер, автоплан, повторы, очки, API (node:sqlite), бот и Notion с моками
```

## Деплой

Порядок важен: **база → Worker → секреты → бот → Notion**.

### 1. GitHub

- [ ] Создай репозиторий (можно приватный) и залей код.
- [ ] Проверь, что в репо нет токенов: `BOT_TOKEN` и `SERVICE_KEY` живут только в секретах Cloudflare.

### 2. Cloudflare D1 — база

- [x] База `planner` создана, её Database ID уже вписан в `wrangler.toml`
      (`7c4964e8-8f49-404e-a130-f66e2255de75`). Если заведёте новую базу — замените ID на её.
- [ ] SQL руками не нужен — таблицы создаются сами при первом запросе.

### 3. Cloudflare Worker из GitHub

- [ ] **Workers & Pages → Create → Import a repository** → выбери репо.
- [ ] Build command: `npm run build` · Deploy command: `npx wrangler deploy` · Root: `/`.
- [ ] Дождись статуса **Ready** и открой `https://golosovoy-planer.<аккаунт>.workers.dev/api/health` → должно быть `{"ok":true}`.
- [ ] Workers AI и cron подтянутся из `wrangler.toml` сами.

### 4. Секреты

- [ ] Worker → **Settings → Variables and Secrets → Add**, тип только **Secret** (обычные переменные стираются при деплое из Git):
  - `BOT_TOKEN` — токен от @BotFather (обязательно);
  - `SERVICE_KEY` — длинная случайная строка для внешних автоматизаций (по желанию).
- [ ] После добавления секретов нажми **Deploy** ещё раз или сделай пустой коммит.

### 5. Telegram-бот

- [ ] @BotFather → `/newbot` → имя и username → токен в секрет `BOT_TOKEN`.
- [ ] Bot Settings → **Configure Mini App / Menu Button** → URL твоего Worker'а, строго с `https://`.
- [ ] Открой Mini App из бота → **Ещё → Настройки → Telegram-бот → «Подключить бота к планеру»**.
      Вебхук, кнопка меню и команды поставятся сами.

### 6. Notion и Notion Calendar (по желанию)

- [ ] notion.so/profile/integrations → **New integration (Internal)** → скопируй секрет `ntn_…`.
- [ ] Создай пустую страницу «Планер» → **··· → Connections** → добавь интеграцию.
- [ ] В планере: **Настройки → Notion** → вставь секрет и ссылку на страницу → «Подключить».
      Внутри появится база «Планер» (Задача, Когда, Готово, Сфера, Минут, Главное).
- [ ] Notion Calendar: Settings → Notion → добавь базу «Планер», свойство даты «Когда».

### 7. Телефон и компьютер

- [ ] В Mini App: **Настройки → Ключ для браузера → Скопировать**.
- [ ] Открой сайт на компьютере и вставь ключ один раз.
- [ ] На телефоне: «Поделиться → На экран Домой» — планер встанет как приложение.

### Проверка после деплоя

- [ ] `/api/health` отвечает `{"ok":true}`.
- [ ] Голосовое боту «завтра в 11 созвон с клиентом на час» → бот ответил списком → задача в планере.
- [ ] Задача, добавленная на телефоне, появилась на компьютере (и наоборот).
- [ ] Через 5 минут задача с датой видна в Notion Calendar.

## Лимиты (бесплатный тариф Cloudflare)

| Сервис | Лимит | Для одного человека |
|---|---|---|
| Workers | 100 000 запросов в сутки | с огромным запасом |
| D1 | 5 ГБ, 5 млн чтений и 100 000 записей строк в сутки | с огромным запасом |
| Workers AI | 10 000 нейронов в сутки, сброс в 00:00 UTC | хватает на ежедневные голосовые |

## Безопасность

- Токен бота и `SERVICE_KEY` — только в секретах Cloudflare. Никогда в коде, `wrangler.toml` или репозитории
  (в `wrangler.local.toml` лежит только фиктивный токен для локального запуска).
- Засветил токен — сразу перевыпусти его в @BotFather через `/revoke` и обнови секрет.
- Ключ для браузера и секрет Notion никому не показывай: это доступ к твоим задачам.

## Частые ошибки

| Симптом | Причина и решение |
|---|---|
| После деплоя пропал токен бота | Добавлен как обычная переменная. Удали и добавь заново с типом **Secret**. |
| Worker падает на запросах к базе | В `wrangler.toml` остался `REPLACE_WITH_D1_ID`. Вставь свой Database ID и закоммить. |
| Mini App не открывается из бота | URL в BotFather без `https://` или с опечаткой. |
| Бот молчит на сообщения | Не нажата кнопка «Подключить бота к планеру» в настройках Mini App — вебхук не поставлен. |
| Голос не распознаётся | Кончились суточные нейроны Workers AI — сбросятся в 03:00 по Москве. Или смотри `npm run tail`. |
| Задачи не доходят в Notion | Страница не подключена к интеграции (··· → Connections) или у задачи нет даты. |
| На компьютере просит ключ | Это нормально: скопируй ключ в Mini App (Настройки → Ключ для браузера) и вставь один раз. |

## Как это устроено

```
┌────────────────────────────────────────────┐
│                Cloudflare Worker           │
│  dist/* (React PWA)  +  /api/* (worker.js) │
│                                            │
│  /api/auth/telegram  HMAC initData → ключ  │
│  /api/tasks/sync     last-write-wins       │
│  /api/items/sync     last-write-wins       │
│  /api/pull?since=rev push/pull по ревизии  │
│  /api/telegram/webhook  голос/текст → AI   │
│  /api/notion/connect   база «Планер»       │
│  cron */5 мин: Notion + напоминания        │
└───────────────┬────────────────────────────┘
                │ D1 (tasks, items, keys, secrets)
```

- **Синк**: локальная копия главная, правки мгновенно и офлайн; push грязных записей раз в секунду,
  pull при фокусе, возврате в сеть и раз в 30 с; удаления — надгробия; отметки привычек — детерминированные
  id `hl:<привычка>:<дата>`.
- **Авторизация**: initData Telegram проверяется HMAC по токену бота; тот же ключ вставляется в браузере;
  внешние автоматизации — `X-Service-Key` + `X-Telegram-User-Id`.
- **Схема БД** создаётся кодом при первом запросе (CREATE TABLE IF NOT EXISTS + ALTER TABLE для новых колонок).

Структура:

```
server/          Worker: worker.js, api.js, bot.js, notion.js, cron.js, db.js, auth.js, util.js
src/             React: экраны (components/), стор (store.js), синк (sync.js)
src/lib/         логика: парсер ввода, автоплан, повторы, очки, экспорт/импорт, даты
tests/           node:test: логика + API на node:sqlite + бот/Notion с подменой API
wrangler.toml    прод-конфиг (сюда вставляется Database ID)
wrangler.local.toml   локальный конфиг без AI
```
